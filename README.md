# Алгоритм определения стадии ПОУГ по набору биомеханических показателей
 
Репозиторий содержит материалы и код для анализа данных о глаукоме, включая подготовку данных и визуализацию результатов.

## Содержание репозитория

### Jupyter Notebooks:
- **8sem_alg_test.ipynb** - Тестирование алгоритмов определения стадии ПОУГ.
- **8sem_main_body.ipynb** - Основной анализ данных.
- **8sem_preparation.ipynb** - Подготовительные операции с данными (очистка, заполнение пропусков и т.д.).
- **glaucoma_analysis.ipynb** - Анализ данных о глаукоме.

### Вспомогательные файлы:
- **prepare_data.xlsx** - Обработанные данные в формате Excel для 4 групп пациентов.
